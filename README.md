# Exp-1 ATM & BANKING SYSTEM

# AIM:
To design and develop an ATM and Banking System that allows customers to perform banking operations such as cash withdrawal, cash deposit, balance enquiry, fund transfer, and mini statement securely and efficiently.

# SRS (Procedure):

1. Identify the system requirements.
2. Collect user and admin requirements.
3. Define functional and non-functional requirements.
4. Design the six UML diagrams.
5. Develop and test the ATM & Banking System.
6. Verify that all banking operations work correctly.
